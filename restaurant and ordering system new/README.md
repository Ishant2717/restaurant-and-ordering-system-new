# Urban Bite — Restaurant & Ordering System (Front-end)

A responsive, multi-page restaurant website built with **HTML5, CSS3, and vanilla JavaScript only**. No framework, server, database, or build step is required.

## Pages
- `index.html` — landing page, food photography, categories, featured reviews, newsletter demo.
- `menu.html` — searchable and filterable menu, favourites, add-to-cart actions.
- `about.html` — restaurant story, values, and project stats.
- `reviews.html` — sample reviews plus a review form.
- `cart.html` — quantity controls, remove items, subtotal, delivery calculation, demo checkout.
- `contact.html` — contact information and a demo contact form.

## Run locally
1. Extract the ZIP to a folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension in VS Code and click **Go Live**.
4. Navigate between pages using the top navigation.

This is a static website; there is no `npm install` step and no backend language is used.

## Functionality
- Responsive layouts for desktop, tablet, and mobile.
- Menu filtering and search.
- Shopping cart with quantity updates and remove actions.
- Cart count in the header and automatic delivery-fee calculation.
- Favourites saved in `localStorage`.
- Demo checkout with browser-local order history.
- Customer reviews, contact messages, and newsletter entries saved in `localStorage`.
- Form validation, accessible labels, empty states, reduced-motion support, and image fallbacks.

## Important limitations
This is intentionally a **front-end-only portfolio project**. Browser `localStorage` data stays on that device/browser and is not shared with a restaurant owner or other customers. Checkout does not process payments or send orders to a real restaurant. Contact and newsletter forms do not send emails. Demo reviews and ratings are illustrative, not verified customer feedback. Images load from Unsplash and Google Fonts need an internet connection; local placeholder art is included as a fallback.

Before using this for a real business, replace sample contact details, demo ratings, prices, menu content, and images with verified information. A production ordering system would need a backend, database, secure payment integration, and order-management workflow.
